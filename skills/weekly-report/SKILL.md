# Weekly report format

When a task asks for a weekly report, produce it in this exact structure:

## Structure

1. **Subject line:** `Weekly update — <ISO week, e.g. 2026-W34>`
2. **Wins** — max 3 bullets, outcome-first phrasing.
3. **In progress** — what's moving, with expected completion.
4. **Blocked / needs attention** — only if real; name who is needed.
5. **Next week** — max 3 bullets.

## Tone

Plain, direct sentences. No filler ("I hope this finds you well"), no emoji.
Keep the whole report under 200 words.
