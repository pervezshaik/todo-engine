# Example outputs

Files in this folder were produced by task agents during the acceptance runs
recorded in `docs/design.md` §7 (2026-08-22) — e.g. `hello.txt` from the haiku
task, `weather.md` from the web-research task, `github-check.md` /
`gmail-check.md` / `hn-top5.md` from the MCP-connector checks.

They are kept as a reference for what a finished task looks like. Running
`examples/todo.md` with `--workdir examples/outputs` will overwrite them.
